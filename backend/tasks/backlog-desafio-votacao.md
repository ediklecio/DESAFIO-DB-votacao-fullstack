Validar de fato quando o item 7 (docker-compose) subir um Postgres real. *Tamanho: M. Depende de: item 5.*
6b. **[FEITO]** RN01 (extensão) — CPF único por pauta: coluna `votes.cpf` + constraint `UNIQUE(agenda_id, cpf)` (migração `V4__add_cpf_unique_to_votes.sql`, espelhada na entidade `Vote` para o schema H2 dos testes), `VoteRepository.existsByAgendaIdAndCpf` como fast-path e `VoteService.registerVote` checando os dois eixos (`memberId` e `cpf`) antes de persistir — mesmo padrão de dupla guarda (checagem + `DataIntegrityViolationException`) já usado para `memberId`. Garante que um associado não vote de novo trocando de id com o mesmo CPF, nem um CPF já usado vote de novo sob outro id. Cobertura: `VoteServiceTest` (novo caso `shouldThrowWhenCpfAlreadyVotedUnderADifferentMemberId`) e `VotingFlowIntegrationTest` (novo caso `shouldRejectAVoteWhenTheCpfAlreadyVotedUnderADifferentMemberId`, contra o schema H2 real). *Tamanho: S.
